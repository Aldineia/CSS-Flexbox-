CSS FlexBox

É um modelo de layout unidimencional projetado para distribuir espaço e alinhar itens em uma interface de forma responsiva. Ele organiza os elementos através da relação entre um Flex Container (elemento pai) e seus Flex items (elementos filhos).

1. Flex Container e Propriedades Principais

O Flex Container é a tag que envolve todos os itens, tornando-os flexíveis ao aplicar a propriedade display: flex.

Propriedades relacionados:

  • Display: inicia o comportamento do container.
  • Flex-direction: direciona os itens em linha e coluna.
  • Flex-wrap: Controla a quebra de linha dos itens.
  • Flex-flow: abreviação para direction e wrap.
  • Justify-content: alinhar os itens ao longo do eixo principal.
  • Align-items: alinha os itens ao longo do eixo transversal.
  • Align-content: alinha as linhas de itens quando há quebra.

2. Flex Item

Os Flex Items são os elementos filhos diretos do Flex Container. Eles são redimenionáveis e adaptam-se dinamicamente ao espaço disponível.

Propriedades relacionadas:

  • Flex-grow: Define a proporção de crescimento do item.
  • Flex-basis: Define o tamanho inicial do item antes da distribuição de espaço.
  • Flex-shrink: Define a proporção de redução do item se necessário.
  • Flex: Abreviação grow, basis e shrinkk.
  • Order: Altera a ordem visual de distribuição dos itens.
  • Align-self: Permite alinhar um item específico de forma independente, sobrescrevendo o align-items do container.
