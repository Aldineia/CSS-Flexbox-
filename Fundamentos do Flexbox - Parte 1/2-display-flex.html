Fundamentos Flex-Flow

default:row nowrap

row: Organiza os elementos filhos em ums linha horizontal, da esquerda para a direita.

nowrap: Força todos os elementos a ficarem nessa mesma linha. Se não couberem na tela, eles encolhem em vez de quebrar para a linha debaixo.

row-reverse nowrap

row-reverse: O eixo principal permanece horizontal. No entanto, o ponto de partida se inverte.

nowrap: Isso força todos os itens flexíveis a ficarem em uma única linha, impedindo que quebrem para uma nova linha.

row-reverse wrap

row-reverse:Os itens são alinhados na horizontal, mas invertidos. o primeiro item vai para a extremidade direita, e os demais seguem para a esquerda na ordem em que foram declarados.

wrap: Quando a tela ou contêiner for redimensionado e não houver mais espaço na linha horizonal, os elementos que sobrarem passarão para a linha debaixo, formando uma estrutura responsiva.

row-reverse: Os itens são exibidos da direita para a esquerda.

wrap-reverse: Quando ocorre quebra de linha, as novas linhas aparecem acima da linha principal, inverte a direção padrão do empilhamento.

RESUMO

  • row nowrap => Linha horizontal sem quebra;
  • row wrap => Linha horizontal com quebra;
  • row wrap-reverse => Quebra invertida;
  • row-reverse nowrap => Linha invertida com quebra;
  • row-reverse wrap-reverse => Linha invertida e quebra invertida.
