Flex -Grow

É uma propriedade do CSS que define quanto um item pode crescer para ocupar o espaço que sobra dentro do container.

Por padrão, os elementos ocupam apenas o tamanho do seu próprio conteúdo.

Flex Grow 0

Padrão da propriedade, o item manterá seu tamanho original.

A - 0
B - 0
C - 0
D - 0

Flex Grow 1

Define a capacidade de um elemento "crescer" e ocupar o espaço livre restante dentro do seu contêiner.

A - 1
B - 1
C - 1
D - 1

Flex Grow 2

Cresce o dobro da proporção de um item com flex-grow 1.

A - 2
B - 2
C - 2
D - 2

Flex Grow 3

Indica que, ao distribuir o espaço vazio restante, este item específico receberá uma "fatia" 3 vezes maior do que um item que possue flex-grow.

A - 3
B - 3
C - 3
D - 3

Flex -Grow alternados

A - 0
B - - 1
C - -- 2
D - --- 3
