# ✈️ Flex Turismos - Landing Page

Uma landing page moderna, elegante e totalmente responsiva desenvolvida para a **Flex Turismos**, uma agência de viagens fictícia. O projeto foi construído focando em boas práticas de estruturação HTML5 e conceitos avançados de estilização com CSS Flexbox.

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido utilizando as seguintes tecnologias:

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização, layout responsivo com Flexbox, animações e efeitos de *hover*.
- **Google Fonts:** Tipografia utilizada (`Open Sans`).

---

## 📌 Funcionalidades

- **Menu de Navegação Fixo (Sticky Header):** Cabeçalho fixo no topo com rolagem suave (*smooth scroll*) para facilitar a navegação.
- **Seção de Apresentação (Hero Section):** Destaque principal com chamada para ação (*CTA*).
- **Seção Quem Somos:** Informações sobre a empresa com layout invertido e elementos visuais customizados.
- **Seção de Serviços:** Exibição dos serviços prestados em formato de cards interativos.
- **Tabela de Planos:** Apresentação de planos e benefícios alinhados verticalmente com botões integrados.
- **Design Responsivo:** Adaptação completa do layout para telas de smartphones, tablets e desktops.
